# EquiHealth - Accessible Health Management App

A React Native (Expo) app for managing health conditions, medications, meals and reminders, with English and Hindi support and accessibility features.

## 🚀 Quick Start

### Prerequisites
- Node.js 20+ ([Download](https://nodejs.org/))
- The **Expo Go** app on your phone ([iOS](https://apps.apple.com/app/expo-go/id982107779) / [Android](https://play.google.com/store/apps/details?id=host.exp.exponent))

### Run on your phone
```bash
npm install
npx expo start
```
Scan the QR code in the terminal:
- **iPhone:** with the Camera app, then tap the banner.
- **Android:** from inside Expo Go.

Your phone and computer need to be on the same Wi-Fi. If it can't connect, use `npx expo start --tunnel`.

### Environment variables
Copy `.env.example` to `.env` and fill in the values. `.env` is gitignored, so never commit it.

| Variable | Used for |
|---|---|
| `EXPO_PUBLIC_SUPABASE_URL` | Supabase project URL |
| `EXPO_PUBLIC_SUPABASE_ANON_KEY` | Supabase anon (public) key |

Only variables starting with `EXPO_PUBLIC_` reach the app, and anything in them can be read from the app bundle. Don't put secret keys there.

### Native builds (optional)
`npm run ios` / `npm run android` build the native app locally. They need Xcode + CocoaPods (iOS) or Android Studio (Android). The `ios/` and `android/` folders are generated by `npx expo prebuild` and are not committed.

## 📋 Project Structure

```
├── App.js                 # Entry point and navigation (stack + bottom tabs)
├── app.json               # Expo config
├── src/
│   ├── screens/           # App screens
│   ├── context/           # Global state and persistence (AppContext)
│   ├── i18n/              # Translations (English, Hindi)
│   ├── data/              # Illness, medication, diet and info data
│   ├── services/          # Supabase client, auth and database helpers
│   └── theme.js           # Colors, gradients and scaling
├── screens/               # SVG design mockups
└── archive/voice/         # Parked voice feature (not bundled, see its README)
```

## ✨ Features

- 🌐 **Languages:** English and Hindi
- ♿ **Accessibility:** adjustable text size
- 💊 **Health tracking:** medications, meals, blood pressure, glucose and cholesterol logs
- ⏰ **Reminders:** daily local notifications for medications and meals
- 📊 **Condition info:** hypertension, diabetes and asthma diet plans and education
- 🎨 **Clean light theme:** white background, blue and green accents, the [Atkinson Hyperlegible Next](https://www.brailleinstitute.org/freefont/) font (built for low-vision readability)

## 🛠️ Tech Stack

- **Expo SDK 58** / React Native 0.88 / React 19
- **React Navigation 7**: stack and bottom tabs
- **AsyncStorage**: on-device persistence
- **expo-notifications**: local reminders
- **Supabase**: backend client (set up, not yet used by screens)
- **@expo/vector-icons**: Ionicons

## 📱 Screens

- **Language Selection**: choose language and condition
- **Authentication**: name and phone number
- **Profile Setup**: age, text size
- **Home**: next reminder, daily medication and meal checklist
- **Conditions**: manage conditions and medications
- **Diet Plans**: meal plans for your condition
- **Medical Alerts**: medication and meal reminders
- **Disease Info**: condition education
- **All Logs**: health metric and history logs
- **Settings**: language, conditions, text size

## 🔧 Troubleshooting

### App not loading or showing old code?
```bash
npx expo start --clear
```

### Dependency problems?
```bash
rm -rf node_modules package-lock.json
npm install
npx expo install --check
```

### Check project health
```bash
npx expo-doctor
```

## 📝 Development

- **Add a screen:** create it in `src/screens/`, then register it in `App.js`.
- **Add text:** add the key to **both** `en` and `hi` in `src/i18n/translations.js`, then use `t(language, 'key')`.
- **Theme:** edit `src/theme.js`.
